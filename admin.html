How to edit and publish
  1. Select a worksheet and row. Changes are held in this page until you save or download. Required fields are marked with an asterisk.
  2. Use a show's key in each episode's project field. Keep IDs unique and use letters, numbers, underscores or hyphens.
  3. Use plain text in Excel, including durations and dates. Keep sheet names and column headers unchanged. Do not use formulas. The workbook includes a Read Me sheet.
  4. Upload new images separately to the website's image folders, then enter their paths or filenames. An Excel file does not upload images.
  5. Preview and check your changes. Download as website.xlsx, replace data/website.xlsx, and deploy the website. Keep the previous version as a backup.
  6. This is a static editor, not an authenticated admin service. Anyone can download the public workbook, but this page gives them no permission to modify your hosted files. Never put secrets or private information in the workbook.
